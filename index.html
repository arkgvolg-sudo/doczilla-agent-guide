Консультации: AI отвечает сам или подключает юриста

Можно уверенно ответить без профессионального суждения?
ДАAI отвечает
НЕТAI + юрист

Ответа AI достаточно

Справочный или типовой вопрос, где ответ однозначно следует из законодательства, правил или существующей практики.

Признаки такой ситуации
  • Конкретный вопрос
  • Однозначное правило
  • Нет необходимости выбирать юридическую позицию
  • Не требуется существенная оценка рисков
  • Нет сложного исследования практики
  • Типовая ситуация
AI сразу формирует итоговый ответ. Задача юристу не создаётся.

Нужна проверка юриста

Ситуация требует профессионального юридического суждения, оценки рисков, выбора позиции или применения нормы к нетиповой ситуации.

Что обязательно требует проверки
  • Налоговое право
  • Валютное регулирование
  • M&A
  • Уголовно-правовые риски
  • Существенные суммы
  • Действующий спор или претензия
  • Новая / нетиповая ситуация
  • Оценка нескольких вариантов действий
  • Рекомендация «как лучше поступить»
  • Позиция для банка, госоргана, аудитора или контрагента
  • Существенный анализ судебной практики
  • Иностранное законодательство
  • Новая бизнес-модель
AI готовит предварительный ответ → создаёт задачу юристу → юрист проверяет и при необходимости корректирует ответ.
Если ситуация находится на границе двух категорий — запрос передаётся на проверку юристу.

AI сам выбирает подходящего юриста

Назначение происходит не случайно и не на первого найденного специалиста.

A

Подготовка договора

Специализация по типу документа
Определяет тип договора
Проверяет специализации всех доступных юристов
Находит подходящих
Один специалистНазначает его
НесколькоНазначает с минимальной загрузкой
B

Проверка NDA / договора

Приоритет критериев
1Ранее проверял такой тип документа для этого клиента
2В специализации есть тип документа + клиент
3В специализации есть тип документа
4Ранее проверял другие документы этого клиента
5В специализации есть клиент

Более высокий критерий всегда имеет приоритет над более низким.

C

Консультация

Приоритет критериев
1Ранее работал над этой же консультацией
2Специализация по направлению консультации
3Специализация на клиенте
4Ранее выполнял другие задачи для этого клиента

AI проверяет полный список подходящих специалистов и не останавливается на первом совпадении.

Ключевые правила AI-агента

Понимает язык бизнеса

Не требует от пользователя юридической терминологии.

Один вопрос за раз

Не отправляет пользователю длинный опросник.

Не спрашивает дважды

Использует уже предоставленную информацию.

Не придумывает данные

Если информации нет — уточняет.

Файл нужен — ждёт файл

Не продолжает файловый сценарий без документа.

Self-service в приоритете

Если есть типовой шаблон — отдаёт его без задачи юристу.

Соблюдает SLA

Не обещает срок меньше установленного SLA.

Проверяет всех кандидатов

Не назначает первого найденного юриста.

Сохраняет контекст

AI + Human
